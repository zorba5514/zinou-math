# منصة الأستاذ زين الدين للرياضيات

**الرياضيات كما يجب أن تكون.**

منصة تعليمية لدروس الرياضيات من الأولى متوسط إلى الأولى ثانوي، مع دورات منفصلة. تضم حسابات الأولياء والأبناء، والاشتراكات، والدروس، والملفات، والاختبارات. هذا الملف يشرح كيف يعمل المشروع وكيف يُشغَّل ويُعدَّل.

## الحالة الحالية

| المرحلة | الحالة |
| --- | --- |
| 0. التجهيز | قيد المراجعة |
| 1 إلى 9 | لم تبدأ |

وثيقة المشروع الكاملة (المتطلبات، التصميم، خطة التنفيذ) موجودة في Claude Docs. ملخص القرارات التقنية في [docs/DECISIONS.md](docs/DECISIONS.md).

## كيف يعمل المشروع

- **الخادم:** `src/index.ts` يعمل على Cloudflare Workers. يعالج طلبات `/api/*`، ويرسل باقي الطلبات إلى الملفات الثابتة.
- **الصفحات:** مجلد `public/` يضم الصفحات والصور. ترويسات الأمان للصفحات في `public/_headers`.
- **الإعدادات:** `wrangler.toml` يحدد اسم الموقع الحقيقي (`zinou-math`) واسم موقع الاختبار (`zinou-math-staging`).
- **الاختبارات:** مجلد `test/`، وتعمل بأداة الاختبار المدمجة في Node دون مكتبات إضافية.

## طريق كل تغيير

1. يُكتب التغيير في فرع مستقل، مثل `phase-0-setup`.
2. عند رفعه إلى GitHub، يشغّل الملف `.github/workflows/ci.yml` تلقائيًا:
   - فحص الأنواع والاختبارات الآلية.
   - فحص الأسرار (gitleaks): يرفض أي كلمة مرور أو مفتاح داخل الكود.
   - النشر على موقع الاختبار، فقط إذا نجح ما سبق، ثم التحقق من أن الموقع يرد كما يجب.
3. يجرّب الأستاذ التغيير على موقع الاختبار ويوافق عليه.
4. يُدمج الفرع في `main`. النشر على الموقع الحقيقي يُضاف عند شراء النطاق.

نتيجة كل تشغيل تظهر في تبويب **Actions** في المستودع، ورابط موقع الاختبار يظهر في ملخص التشغيل.

## الأسرار

لا توضع أي كلمة مرور أو مفتاح في الكود أبدًا. الأسرار محفوظة في GitHub: Settings ← Secrets and variables ← Actions.

| الاسم | الاستعمال |
| --- | --- |
| `CLOUDFLARE_API_TOKEN` | مفتاح النشر على Cloudflare. صلاحياته: Workers وD1 لحساب واحد. إن كانت له مدة صلاحية، يجب تجديده قبل انتهائها وإلا يتوقف النشر. |
| `CLOUDFLARE_ACCOUNT_ID` | معرّف حساب Cloudflare. |

إذا شككت أن المفتاح تسرّب: احذفه من Cloudflare (Manage account ← Account API tokens)، وأنشئ مفتاحًا جديدًا، وضعه مكان القديم في GitHub.

## التشغيل على حاسوب (للمطوّر)

يحتاج Node 22.18 أو أحدث.

```bash
npm install        # تثبيت الأدوات
npm run check      # فحص الأنواع والاختبارات
npm run dev        # تشغيل الموقع محليًا
```

للتجربة المحلية توضع الأسرار في ملف `.dev.vars`، وهو مستبعد من المستودع.
